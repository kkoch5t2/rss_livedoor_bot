# 汎用RSS ニュース解説自動投稿ボット

指定したRSSフィード（ニュースサイト、ブログ等）を定期的に監視し、新着記事の内容をスクレイピングして、生成AI（Google Gemini）による「解説・考察」を交えたブログ記事を自動生成し、Livedoorブログへ自動投稿するシステムです。

## 主な機能
- **汎用RSSフィード監視**: 任意のRSSフィード（複数設定可能）から新着記事を自動検出。ジャンルを問わず利用可能です。
- **AIによる解説記事生成**: 単なる要約だけでなく、Geminiを活用して深い分析や考察を交えた読み応えのあるHTML記事を生成。
- **引用カード生成**: 元記事のサムネイル画像やタイトルを綺麗なリンクカード形式（HTML）で自動付与。
- **重複防止**: 一度処理した記事のURLを履歴として保持し、二重投稿を防止。
- **セキュアな設計**: APIキーなどのシークレット情報を環境変数から読み込む仕様となっており、安全に公開・運用が可能。

> [!NOTE]  
> **💡 特殊機能：「IT系ニュース」モード**
> 設定（`settings.json`）の `name` 項目を完全に `"IT系ニュース"` に設定した場合のみ、AIへの指示が「データエンジニアやSREの視点による技術的な深堀り」モードに切り替わる隠し機能が実装されています。技術ブログのまとめサイトを運営する際に非常に便利です。
> それ以外の名前（例：`"経済ニュース"`, `"エンタメ"` など）を指定した場合は、一般的な「記事の分析・考察」を行うモードになります。

## 必要要件
- Docker Desktop
- Docker Compose (v2)

## セットアップと設定

本プロジェクトは設定ファイルと環境変数を用いて動作します。

### 1. 環境変数 (`.env`)
プロジェクトルートに `.env` ファイルを作成し、Google GeminiのAPIキーを設定してください。カンマ区切りで複数設定することで、無料枠の制限を回避するローテーション機能が利用できます。
```env
AI_KEYS=YOUR_GEMINI_API_KEY_1,YOUR_GEMINI_API_KEY_2
```

### 2. メディア設定 (`src/settings.json`)
`src/settings.example.json` をコピーして `src/settings.json` を作成し、Livedoorブログの認証情報と取得先RSSフィードURLを設定してください。
```json
[
  {
    "name": "一般的なニュースまとめ", 
    "blog_id": "YOUR_LIVEDOOR_BLOG_ID",
    "user_id": "YOUR_LIVEDOOR_USER_ID",
    "api_key": "YOUR_LIVEDOOR_API_KEY",
    "target_urls": [
      "https://example.com/rss"
    ]
  }
]
```
※技術ブログ向けに特化させたい場合は、`"name": "IT系ニュース"` と設定してください。

## 起動方法

### ローカルでの実行
Docker Composeを使用してコンテナを起動します。
```bash
docker-compose up --build
```

### Jenkinsでの定期実行（推奨）
本リポジトリには `Jenkinsfile` が含まれています。
Jenkinsのパイプラインジョブでこのリポジトリを指定し、「パラメータ付きビルド」で `MEDIA_SETTINGS_JSON` と `AI_KEYS` を渡すことで、シークレット情報をGitに含めずに安全に定期実行を行うことができます。
